# 康威生命游戏 (Conway's Game of Life)

这是一个基于终端的康威生命游戏实现，使用 `ncurses` 渲染界面，并支持鼠标输入、键盘控制、速度调节、状态检测与种子保存。

## 主要特性

- **经典规则**：实现康威生命游戏的标准生死规则
- **鼠标编辑**：在游戏开始前使用鼠标点击格子设置初始状态
- **键盘控制**：支持 `+`/`=` 加速，`-`/`_` 减速，`r` 重置速度，`q` 退出
- **撤销/重做**：支持 `←` 撤销到上一世代，`→` 前进一步（`redo` 或 `advance`）
- **状态检测**：自动检测稳定状态、循环状态与全死亡状态
- **种子保存**：有效初始种子会保存到 `seed.txt`
- **终端友好**：使用 UTF-8 宽字符绘制图形界面

## 游戏规则

每一代细胞状态同步更新：

1. 死亡细胞周围恰好 3 个活细胞时变为活细胞
2. 活细胞周围少于 2 个活细胞时死亡（孤独）
3. 活细胞周围有 2 或 3 个活细胞时继续存活
4. 活细胞周围超过 3 个活细胞时死亡（过密）

游戏区域内部为 30×30，边界用墙体（🧱）表示，不可编辑。

## 运行环境

- C++17 兼容编译器（例如 `g++`）
- `ncurses` 库
- UTF-8 终端
- 必须在真实交互式终端中运行，不适合非交互式控制台

### Ubuntu/Debian 安装依赖

```bash
sudo apt install g++ libncurses-dev
```

## 编译

在项目根目录运行：

```bash
make
```

生成可执行文件：

```bash
./bin/gameoflife
```

清理编译产物：

```bash
make clean
```

## 启动参数

| 参数               | 描述                             |
| ------------------ | -------------------------------- |
| 无参数             | 直接进入游戏                     |
| `-d` / `--direct`  | 直接进入游戏                     |
| `-r` / `--rule`    | 显示游戏规则后进入游戏           |
| `-h` / `--help`    | 显示帮助信息                     |

示例：

```bash
./bin/gameoflife -r
./bin/gameoflife -h
```

## 游戏控制

| 操作       | 功能                                      |
| ---------- | ----------------------------------------- |
| 鼠标左键   | 点击内部格子切换细胞状态                   |
| 空格       | 完成种子设置并开始模拟                     |
| `+` / `=`  | 加速                                       |
| `-` / `_`  | 减速                                       |
| `r` / `R`  | 重置速度为默认值                           |
| `q` / `Q`  | 退出游戏                                   |
| `←`        | 撤销到上一世代                              |
| `→`        | 重做 / 前进一步                              |

## 游戏结束条件

游戏会在以下情况下自动结束并显示结果：

- **所有细胞死亡**：无活细胞剩余
- **状态稳定**：当前世代与上一世代相同
- **循环状态**：此前已出现过相同布局
- **用户退出**：按 `q` 或 `Q`

如果当前种子包含活细胞，程序会将其保存到 `seed.txt`。

## 种子保存格式

`seed.txt` 中的保存条目包含时间戳、迭代次数和细胞矩阵数据。

## 项目结构

- `src/`：源代码
  - `main.cpp`：程序入口、参数解析与规则页
  - `gameOfLife.cpp`：游戏核心逻辑、渲染和输入处理
  - `getInput.cpp`：初始种子编辑界面与鼠标输入
  - `gameStatusDetect.cpp`：稳定/循环状态检测
  - `seedSaver.cpp`：将有效初始种子保存到文件
- `include/`：头文件
- `bin/`：生成的可执行文件
- `obj/`：中间对象文件
- `seed.txt`：保存的种子历史

## 注意事项

- 程序依赖终端支持 UTF-8 和宽字符
- 如果终端异常退出导致光标不可见，可执行 `reset` 恢复
- 背景音乐文件位于 `~/Music/`，请手动复制并重命名为 `audio.mp3` ，若缺失则游戏仍可运行但无音乐
