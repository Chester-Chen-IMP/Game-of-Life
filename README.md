# 康威生命游戏 (Conway's Game of Life)

一个基于终端的康威生命游戏实现，支持鼠标交互、速度调节、状态检测和种子保存。

## 特性

- **经典规则**：准确实现康威生命游戏的四种生存/死亡定律
- **鼠标交互**：在游戏开始前，使用鼠标点击格子设置初始细胞（种子）
- **速度调节**：按 `+`/`-` 实时调整演化速度（对数变化，共 21 级）
- **状态检测**：自动检测并报告稳定状态、循环状态或全细胞死亡
- **种子保存**：非空种子自动保存到 `seed.txt`，包含时间戳
- **规则查看**：启动参数支持显示详细游戏规则
- **键盘控制**：完整快捷键，无需鼠标也可退出或重置速度

## 游戏规则

康威生命游戏是一个零玩家游戏，每一代细胞状态根据以下规则同步更新：

1. **繁殖**：死亡细胞周围恰好有 3 个活细胞时，该细胞变为活细胞。
2. **孤独**：活细胞周围活细胞数少于 2 个时，该细胞死亡。
3. **存活**：活细胞周围有 2 或 3 个活细胞时，继续存活。
4. **过密**：活细胞周围活细胞数超过 3 个时，该细胞死亡。

游戏区域为 30×30（内部有效区域），边界为墙壁（🧱），不可编辑。

## 操作指南

| 按键          | 功能                       |
| ------------- | -------------------------- |
| 鼠标左键      | 点击内部格子切换细胞生死   |
| 空格          | 完成种子设置，开始模拟     |
| `+` 或 `=`    | 增加速度等级（更快）       |
| `-` 或 `_`    | 降低速度等级（更慢）       |
| `r` 或 `R`    | 重置速度等级到默认（正常） |
| `q` 或 `Q`    | 退出游戏/模拟              |
| 鼠标点击边框无效（仅内部 30×30 有效）|                |

**速度等级说明**：

| 等级范围  | 描述         | 延迟时间（约） |
| --------- | ------------ | -------------- |
| -10 ~ -8  | EXTREMELY SLOW | 5.0s ~ 2.2s    |
| -7 ~ -5   | VERY SLOW      | 1.5s ~ 0.66s   |
| -4 ~ -2   | SLOW           | 0.44s ~ 0.20s  |
| -1 ~ 0    | NORMAL         | 0.13s ~ 0.50s  |
| +1 ~ +2   | FAST           | 0.33s ~ 0.22s  |
| +3 ~ +5   | VERY FAST      | 0.15s ~ 0.07s  |
| +6 ~ +8   | EXTREMELY FAST | 0.04s ~ 0.02s  |
| +9 ~ +10  | TELEPORTATION  | 0.01s          |

## 编译与运行

### 依赖

- C++17 兼容编译器（g++/clang）
- ncurses 库
- UTF-8 终端（支持宽字符与 Emoji）

Ubuntu/Debian 安装依赖：
```bash
sudo apt install libncurses-dev g++
```

### 编译

项目使用 Makefile 构建。在项目根目录执行：

```bash
# 调试模式（含地址消毒剂）
make

# 发布模式（优化）
make release

# 清理构建文件
make clean
```

### 运行

```bash
./game_of_life
```

#### 命令行参数

| 参数               | 说明                             |
| ------------------ | -------------------------------- |
| 无参数             | 直接进入游戏                     |
| `-d` / `--direct`  | 直接进入游戏（同无参数）         |
| `-r` / `--rule`    | 先显示游戏规则，确认后进入游戏   |
| `-h` / `--help`    | 显示帮助信息                     |

示例：
```bash
./game_of_life -r      # 显示规则后进入
./game_of_life -h      # 查看帮助
```

## 游戏结束条件

游戏自动退出并显示原因：

- **所有细胞死亡**：无活细胞剩余
- **状态稳定**：连续两代细胞布局完全相同（静止图案）
- **循环状态**：布局重复出现（振荡器）
- **用户中断**：按 `q` 或 `Q` 主动退出

无论何种退出，若种子非空都会自动保存到 `seed.txt`。

## 种子保存示例

`seed.txt` 内容格式：
```
Seed saved at 2026-05-22 15:30:45 {
1, 0, 0, 1, ...
0, 1, 1, 0, ...
...
}
```
每行对应细胞矩阵的一行，`1` 表示活细胞，`0` 表示死亡。

## 常见问题

**Q: 鼠标点击没有反应？**  
A: 请确保终端支持鼠标事件（大多数现代终端支持）。如果在 `tmux` 或 `screen` 中运行，可能需要启用鼠标支持。

**Q: 宽字符显示为乱码？**  
A: 设置终端编码为 UTF-8，并安装支持 Emoji 的字体。程序已自动设置 `LANG` 环境变量。

**Q: 运行后光标消失？**  
A: 正常现象，程序会隐藏光标。退出后自动恢复。如果异常退出导致光标消失，执行 `reset` 命令恢复终端。

**Q: 如何调整窗口大小？**  
A: 程序预设屏幕宽度 179 列、高度 48 行。若终端小于此尺寸，界面可能错位。请最大化终端或调整字体大小。
